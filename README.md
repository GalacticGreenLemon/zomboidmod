# Viewpoint Model Fix

An add-on for [Viewpoint](https://steamcommunity.com/sharedfiles/filedetails/?id=3809306528), the first-person mod for Project Zomboid Build 42.
Viewpoint builds most furniture out of the flat isometric sprites, and that looks wrong on shapes like urinals, toilets, sinks and shelves.
This mod uses Viewpoint's own **model packs** to replace those sprites with real low-poly 3D models.
It doesn't change Viewpoint itself.

![the models](docs/preview.png)

## Install

1. Copy `Contents/mods/ViewpointModelFix` to `C:\Users\<you>\Zomboid\mods\ViewpointModelFix`.
2. Enable **Viewpoint Model Fix** in the mod list, after Viewpoint.
3. In Viewpoint's settings window (DELETE), check that **World → Model packs** has this pack on.
   Also check that **Levels of detail → Model packs' models within (chunks)** isn't 0.

## Hooking models up to sprites

Each model needs a `bind.` line in `42/media/viewpoint/ViewpointModelFix/pack.txt` naming the game sprite it replaces.
Every direction an object faces is a separate sprite.
This mod comes with a helper that writes those lines for you:

1. Stand in a bathroom or storage room and press **F7**.
2. Open `Zomboid/Lua/ViewpointModelFix_binds.txt`. You'll find something like this:
   ```
   bind.fixtures_bathroom_01_0=toilet,0,0,0,0,1   # Toilet / Fancy, facing S
   # no model yet: walls_interior_bathroom_01_12   (? / ?, facing ?)
   ```
3. Paste the `bind.` lines at the end of `pack.txt` and restart the game.

If a model comes out turned the wrong way, change its degrees (0, 90, 180 or 270).
If every model is wrong in the same way, change `ViewpointModelFix.DEGREES` in `media/lua/client/ViewpointModelFix.lua` instead.
If one is in the wrong spot, nudge its x/y/z, which are measured in tiles.

## Bind format

```
model.<key>=<file>.obj
bind.<sprite name>=<model key>,<degrees>,<x>,<y>,<z>,<scale>
```

Models are Wavefront OBJ files. Each one names a `.mtl` file whose `map_Kd` is a PNG texture.
One unit is one tile, Y is up, and the tile's centre is the origin.

## Changing or adding models

The models and the texture atlas are generated by `tools/build_models.py`, using Python and Pillow.
Edit the shapes there, then run:

```
python3 tools/build_models.py     # writes the OBJ files and atlas.png
python3 tools/preview_models.py   # renders them to previews/
```

You can also make a model in Blender. Export it as OBJ with Y up and a PNG texture.
Put it next to `pack.txt`, add a `model.` line for it, and bind sprites to it.
